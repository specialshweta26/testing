# Chitchat

A minimal streaming AI chat app built with Next.js, TypeScript, and the Vercel AI SDK.

## Run locally

1. Install Node.js 20+.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and set `OPENAI_API_KEY`.
4. Run `npm run dev` and open http://localhost:3000.

## Production build

Run `npm run build`, then `npm start`.

Keep API keys private; never commit `.env.local`.
