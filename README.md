# goodday groceries

A polished grocery storefront MVP built with Next.js 15, React 19, and TypeScript.

## Run locally

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev` and open http://localhost:3000.

## Production build

Run `npm run build`, then `npm start`.

The catalog and checkout are demo-only; no payment is collected. The existing `/api/chat` route and `hello.py` are preserved.
